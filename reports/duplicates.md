# Duplicate detection

Images analysed: 54,304. Excluded outlier: 1 (the `.png` pepper-fruit photo, see `reports/audit.md`). Generated by `src/dataset/duplicates.py`.

## 1. Exact duplicates (identical file bytes)

Groups with more than one file: 21, covering 42 files (21 redundant copies). Groups spanning more than one class: 0. Groups spanning both train and val: 10.
